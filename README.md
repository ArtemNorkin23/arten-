# Bowling Canvas (Flask)

Мини-сайт на Flask с одним маршрутом `/`: страница содержит Canvas, а JavaScript отрисовывает дорожку, шар и 10 кеглей.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Перейдите в браузере на http://127.0.0.1:5000/ — увидите холст с дорожкой боулинга, шаром и пирамидой кеглей.
